# TG OS Common Charter (referenced by every department)
Standing laws, non-negotiable: (1) ONE system - the TG OS is the record; (2) fully dynamic - everything computed live; (3) NO FAKE DATA ever - honest empty states; (4) no code edits to operate - config is DB rows. Hard rules: theme LOCKED (neon green brand, no purple, no grey/pastel icons, Figtree font) - never touch theme tokens; no abbreviations in user-facing text; sitewide color code green=good red=issue amber=watch; ClickUp/external sharing requires owner per-item approval; verify against the live system before reporting; log every finding in actions_register; deploy ritual: build -> stage tg_deploy -> fresh Netlify token -> deploy -> commit at repo root.
