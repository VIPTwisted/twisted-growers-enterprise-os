The Rules

1. Status colors are reserved. If something shows a STATE, it uses Layer 1 only. Red always means act. Yellow always means watch. Green always means healthy. No decorative use, ever.
2. Department colors mark ownership. Menu categories, module headers, card accents, report tags — the department's color travels with its records everywhere they appear.
3. No new colors without amending this code. The code lives in the database (Law #4) — approved changes update data, not code.
4. Both themes honor the same code. Light mode uses deepened variants of the same hues where white backgrounds demand contrast — the meaning never shifts.
