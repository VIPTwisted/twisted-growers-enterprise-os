Install (once per computer)
1. Unzip. You must SEE a file named manifest.json in the folder you pick.
   If you see another folder named tg-ai-ext, open THAT one.
2. Chrome → chrome://extensions → Developer mode on
3. If a TG Bots card is already there, click Remove on it first.
4. Load unpacked → pick THIS folder (the one with manifest.json)
   Never pick the zip. Never pick an empty folder named TG AI Extention.
5. The card must say 1.3.0.
6. Open the live OS → Bots → tap Grok. A new tab opens. Press Allow.
7. Stay signed in on grok.com.
