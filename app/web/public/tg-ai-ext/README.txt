TG Bots — Chrome / Edge add-on for Twisted Growers OS

Uses Grok, Claude, GPT, or Grok Bots you already pay for. No extra API bill.

Install (once per computer)
1. Unzip this folder.
2. Chrome or Edge → chrome://extensions (or edge://extensions)
3. Turn on Developer mode
4. Load unpacked → pick this folder
5. Open the TG Bots icon
6. Paste the same bridge token the desktop already uses (bridge/token.txt)
7. Pick Grok / Grok Bots / Claude / GPT
8. Turn Running on
9. Stay signed in on that site in a tab

Security
- Token is stored only on this computer (chrome.storage.local). It does not sync.
- Token is never logged. It is sent only to the OS queue as a header.
- Pages we touch: grok.com, claude.ai, chatgpt.com, and the OS queue.
- We type the question as text. We never run it. We never read passwords.
- Metrc stays read-only. Hard gate still holds.

Toggle
Pick Grok, Grok Bots, Claude, or GPT in the popup. Change any time.
For Grok Bots, paste your Buddy bot https://grok.com/… address.
