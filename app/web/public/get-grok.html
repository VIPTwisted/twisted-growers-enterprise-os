Get Grok on this computer

Five clicks, once. Chrome will not let the OS do this for you. After this, every desk can ask Grok.

1 Download

Save the file. Do not open it yet.

Download TG Bots

2 Extract all

Open Downloads. Click the zip once. At the top of the window click Extract all, then Extract.

A new folder opens. You must see a file named manifest. If you see a folder named tg-ai-ext, open that one.

3 Remove the old add-on

In Chrome’s address bar type chrome://extensions and press Enter.

If you see a card named TG Bots, click Remove on that card. Confirm. We will load the new one next. Do not leave 1.2.0 on this computer.

4 Load the new folder

Turn Developer mode on (top right).

Click Load unpacked. Pick the folder from step 2 — the one that contains manifest.

Do not pick TG AI Extention. That folder is empty. Do not pick the zip. Pick the extracted folder.

The card must say TG Bots 1.3.0.

5 Press Allow, then ask HI

Come back to the OS → Bots → tap Grok.

Chrome opens a new tab that says Allow. That is the only Allow. Press it.

Stay signed in on grok.com. Ask HI on any desk.

Open the OS
